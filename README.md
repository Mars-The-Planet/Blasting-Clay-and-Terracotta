<center><p style="text-align: center;">This fully configurable mod allows you to smelt Clay, Clay Blocks, and Terracotta two times faster in the Blast Furnace than in the regular Furnace.</p>
<p style="text-align: center;">&nbsp;<img src="https://i.imgur.com/haJFk6e.png" alt="" height="270" /><img src="https://i.imgur.com/i7ZQEF8.png" alt="" height="270" /><img src="https://i.imgur.com/rmPI78y.png" alt="" height="270" /></p></center>
<details>
<summary><strong>Configuration</strong></summary>
<p>You can configure this mod directly in-game or edit the JSON file <code>config/blastingclay.json</code> in your profile folder. Please note that any changes will require restarting Minecraft to take effect.</p>
<center>
<p style="text-align: center;"><p style="text-align: center;"><b>blasting_list</b> - A list of strings where each string represents a blasting recipe, specifying the input item, the output item, and the exp gained from blasting</p>
